# State Flagle

Flagle-style game with US state flags. 6 guesses, 6 squares; every guess uncovers one more square.

- Static, no build step. Open `index.html` or serve the folder.
- Daily flag and reveal order are seeded from the local date. Practice mode picks a random flag.
- Stats and today's progress live in `localStorage`.
- Flag images from flagcdn.com (`flags/*.png`).
