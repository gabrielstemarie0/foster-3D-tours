# Foster 3D Tours website

Static site (plain HTML/CSS/JS, no build step). Hosted on Cloudflare Pages.

## Quick edits
Open `main.js` and change the two lines at the top:
- `CONTACT_EMAIL`: where "Request a scan" messages go
- `SAMPLE_TOUR_URL`: a share link to a live sample tour (shows it embedded on the page)

## Cloudflare Pages settings
- Framework preset: None
- Build command: (leave empty)
- Build output directory: `/`
